how it works

01

a fake popup appears

looks like a real Windows alert, antivirus warning, email, or browser dialog.

02

you have seconds to decide

spot the tells: weird domain, sketchy wording, broken meter, wrong icon.

03

report → if it's a virus. ok → if it's safe. one life. wrong call = game over.
